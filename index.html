Meus resumos de estudo, tudo em um lugar

Escolha a disciplina para ver os assuntos. Cada assunto abre o resumo e o caderno do TEC.

Como adicionar um resumo novo (ou o link do TEC)
Abra este arquivo index.html e vá até o bloco DADOS (dentro de <script>). Dentro da disciplina, adicione uma linha:

{ nome:"Competência Tributária", html:"direito-tributario/competencia.html", tec:"" }

• html = caminho do seu resumo (deixe "" enquanto não existir → aparece "pendente").
• tec = cole aqui o link do caderno de exercícios do TEC quando tiver. Vazio = o botão some.

Para publicar: suba este index.html e suas pastas no GitHub Pages ou no Netlify Drop. Recomendo uma pasta por disciplina (ex.: direito-tributario/) e os HTMLs dentro dela — assim os caminhos acima funcionam sozinhos.
